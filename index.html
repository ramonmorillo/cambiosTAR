cambiosTAR

Registro, análisis e informes de cambios de tratamiento antirretroviral.

cambiosTAR funciona directamente en el navegador. Los datos se guardan exclusivamente en este navegador/equipo y pueden exportarse en Excel, CSV y JSON para copia de seguridad.

Privacidad local: esta herramienta no tiene backend, no envía datos a servidores externos y no debe utilizarse como historia clínica ni como sustituto de sistemas corporativos.

Configuración de seguridad

Clave local, persistencia y borrado seguro

¿Dónde se guardan los datos?

Los registros se almacenan en IndexedDB dentro de este navegador. Si IndexedDB no estuviera disponible, la aplicación usa localStorage como respaldo. No se suben archivos ni registros a ningún servidor.

Al usar la búsqueda CIMA, solo se consulta el texto del medicamento. Nunca se envían números de historia clínica ni datos de pacientes.
  • La copia de seguridad depende del usuario.
  • No introduzca nombres, DNI, teléfonos, direcciones ni texto libre identificativo.
  • No suba archivos reales al repositorio GitHub.

Clave local de seudonimización

La clave se combina con el número de historia clínica para generar un patient_id SHA-256 estable antes de guardar el registro. La clave no aparece en exportaciones.

La clave se guardará solo en el localStorage de este navegador con el nombre cambiosTAR_pseudonymization_key.

4. Dashboard económico

La codificación de TAR no distingue entre mayúsculas y minúsculas. Por ejemplo, DOR, dor y Dor se interpretan como el mismo componente. La herramienta también intenta resolver nombres comerciales con componentes entre paréntesis, combinaciones separadas por coma, punto y coma o +, y equivalencias de orden entre componentes.

Copias y exportación

Backups y descargas

Al tratarse de una herramienta sin backend, la copia de seguridad depende del usuario. Se recomienda exportar periódicamente un backup JSON y una copia Excel/CSV.

La plantilla incluye: Fecha, Número de historia clínico, TAR antiguo, TAR nuevo y Motivo. El backup JSON incluye también el diccionario TAR local personalizado. No debe subirse a GitHub ni compartirse con datos reales.

Protección de datos

Cumplimiento LOPD-GDD y RGPD

Herramienta diseñada para minimizar datos: almacenamiento local, seudonimización SHA-256 del número de historia clínica y ausencia de backend propio. Use siempre claves locales robustas, datos mínimos y las normas de su centro.
