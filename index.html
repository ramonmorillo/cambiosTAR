Capacidades

Un flujo completo para revisar cambios de tratamiento sin ampliar el modelo de datos con variables clínicas manuales nuevas.

App real

Instalación local

Ejecuta la aplicación operativa en tu equipo. GitHub Pages es solo documentación pública.

git clone https://github.com/<usuario>/cambiosTAR.git
cd cambiosTAR
python -m venv .venv
source .venv/bin/activate        # Linux/macOS
.venv\Scripts\activate           # Windows PowerShell
pip install -r requirements.txt
cp .env.example .env             # Windows: copy .env.example .env
streamlit run app.py

Privacidad

Protección de datos

Procesamiento local

No se suben datos a servidores externos desde la aplicación. El análisis se realiza en la sesión local de Streamlit.

Seudonimización

El número de historia se transforma mediante SHA-256 y una clave local definida en .env.

Gestión de secretos

La clave debe almacenarse en .env. Ese archivo no debe subirse nunca a GitHub.

Repositorio seguro

Añade .env, datos reales y exportaciones sensibles a .gitignore. Los ejemplos deben ser siempre ficticios.
